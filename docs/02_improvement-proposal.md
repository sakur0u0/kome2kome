# 02. 改善提案 — 「墨から金へ」

## コンセプト

> **食べ歩きなのに、この豪華さ。それが、米と米。**
> Street food, elevated. — KOME TO KOME, Gion.

一杯のクレープ・一皿のモンブランに、日本の主食「米」の全てを注ぐ店。
LP は **水墨画の静かな世界（墨・和紙・朱印）から始まり、スクロールするほど色と金が満ちていく**
一巻の絵巻物として設計する。ブランドの起点（筆文字ロゴ・モノトーン）と、店の狙い（豪華・新感覚）を
1 本のスクロールで語る構成。

### 色の物語（スクロール進行で変化）

| 幕 | 背景 | 主色 | 演出 |
| --- | --- | --- | --- |
| 序（Hero） | 漆黒 + 祇園の写真 | 白・金 | 現行を維持（微調整のみ） |
| 破（物語の始まり） | **和紙 #F4EFE6** | 墨 #1A1A1A、薄墨 | 写真はモノクロ。墨の滲みで文字が現れる |
| 急へ向かう（こだわり・品書き） | 和紙 → 墨へ暗転 | 墨 + **朱 #B3262E**（落款） | 写真が**スクロールに連動して色を取り戻す** |
| 急（体験・お米・空気） | **漆黒 #0A0A0A** | 金 #D4AF37 | 金箔が舞い、グローが増す。金の密度はスクロール量に比例 |
| 結（アクセス・Footer） | 漆黒 | 金 + 朱 | 落款が押されて締まる |

- **Plan A（推奨）**: 上記の通り「和紙の明るい幕」を挟む。水墨画→豪華の対比が最も強い。
- **Plan B（代替）**: 全編漆黒を維持し、墨は「白い筆致」として表現。統一感は高いが対比は弱い。

### 3 言語について

- 章題（壱・弐…）と漢字モチーフは全言語共通の「意匠」として残し、本文のみ翻訳する。
- 英語・中国語では章題の横にラテン語キャプション（Craft / Menu / The Ritual…）を主表示に切り替え。
- 価格は円表記のまま、英中では "¥1,650 (tax incl.)" を付与。

## アニメーション設計（日本的モチーフ）

| 演出 | 実装方針 | 使用箇所 |
| --- | --- | --- |
| **墨の滲み（にじみ）** | SVG `feTurbulence` + `feDisplacementMap` で歪ませたマスクを `mask-image` に。`useScroll` でマスクの半径を進める | 壱の見出し、写真の出現 |
| **筆文字の一画描き** | KanjiVG の筆順パス（CC BY-SA）を Framer Motion `pathLength` で順に描く。線幅を筆圧風に太細 | 「米」「極」「静」「縁」などの章モチーフ |
| **色の目覚め** | `useTransform(scrollYProgress → filter: grayscale(1→0) / saturate)` を画像に適用 | 弐（こだわり）の写真 |
| **朱の落款スタンプ** | scale 1.3→1 + rotate −6°→−3° を spring で。押印音は無し。わずかなインク溜まりを内側シャドウで | 章番号、季節限定バッジ、Footer |
| **巻物（横スクロール）** | sticky コンテナ内で `x` をスクロールに紐付け。両端に木軸の意匠 | 参（品書き） |
| **スクロール・スクラブ動画** | `<video>` の `currentTime` を `scrollYProgress` で制御（動画が無い場合は連番写真） | 四（体験） |
| **金箔パーティクル** | Canvas に軽量な粒子。密度・輝きを全体スクロール進捗に比例させ、下へ行くほど増える | 四以降 |
| **暖簾（のれん）** | メニュー開閉・言語切替時に、画面が左右 2 枚の布としてめくれる | モバイルメニュー、言語切替の全画面トランジション |
| **縦書き・一字ずつ置く** | 縦書きコピーを 1 文字ずつ opacity + blur で stagger | 各章のリード文 |
| **和紙テクスチャ** | 現行のノイズに加え、繊維感のある和紙 SVG パターンを Plan A の白背景に | 壱〜弐 |
| **カスタムカーソル**（PC のみ） | 墨点のカーソル、金の残像トレイル | 全体 |

すべて `prefers-reduced-motion` で静的表現に切り替える。重い演出（Canvas・動画スクラブ）はモバイルで軽量版に落とす。

## デザインシステムの拡張

```
既存: base #0A0A0A / gold #D4AF37 / ivory #F5F5F5 / mist #888888
追加: washi #F4EFE6（和紙）/ sumi #1A1A1A（墨）/ usuzumi #6B6B6B（薄墨）
      shu #B3262E（朱・落款）/ gold-leaf gradient（金箔）
```

- 見出し書体は現行維持（Noto Serif JP / Cinzel / Noto Serif SC）。章モチーフの漢字のみ**筆文字（例: Yuji Syuku / Zen Antique）**を追加検討。
- ロゴは実物 SVG（白丸 + 筆文字「米」+ 落款）へ差し替え。

## 期待効果

- 「和食ダイニング」という誤ったポジションから、**祇園で唯一の"米スイーツ体験"**という正確で強い訴求へ。
- 水墨画 → 金の一貫した物語で「日本らしさ」と「豪華」を同時に伝え、インバウンド層の写真撮影・来店動機を作る。
- 予約導線ではなく、**Instagram フォロー + 経路案内**という実態に合った CTA で行動へつなげる。
